# ARCHEA WORKSPACE · aggiornamento v0.3.0

Questo è un pacchetto **incrementale**: contiene soltanto file nuovi o modificati rispetto alla v0.2.3.

## Caricamento su GitHub

1. Estrai lo ZIP.
2. Entra nella cartella `ARCHEA_WORKSPACE_UPDATE_v030`.
3. Seleziona tutto il contenuto (`index.html`, `assets`, `sorgenti` e questo file).
4. Nella repository GitHub scegli **Add file → Upload files** e trascina la selezione.
5. Conferma **Commit changes**.

Non eliminare dalla repository le cartelle `icons` né il file `assets/xlsx-Cznzrv2E.js`: sono invariati e continuano a essere usati.

Al termine apri l'app e verifica che nel piè di pagina compaia **v0.3.0**. Se iPhone mantiene la vecchia versione, chiudi l'app dalla schermata multitasking e riaprila; in caso contrario rimuovi e aggiungi nuovamente il collegamento dalla schermata Home.

## Funzioni incluse

- ruoli Architect, Senior Architect, Partner Architect e Property;
- permesso di modifica predisposto da Senior Architect in su;
- Cantiere con progetti attivi, task/check-list e acquisizione/rinomina foto;
- selezione italiano/inglese memorizzata sul dispositivo;
- Calendario, prenotazione auto/materiale/sale e IN ARCHEA;
- configurazione predisposta per login Google Workspace, Drive e Calendar.

## Funzioni ancora dimostrative

Login aziendale, sincronizzazione foto su Drive, eventi/calendari, prenotazioni, contenuti editoriali e modifiche ai dati richiedono la configurazione Google Workspace e una sorgente dati scrivibile. Il file `sorgenti/src/config/google.js` non deve contenere segreti privati.
